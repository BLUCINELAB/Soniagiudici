# Sonia Giudici Portfolio

Sito statico base per GitHub Pages.

## Struttura

- `index.html` homepage e portfolio
- `about.html` pagina bio
- `contact.html` pagina contatti
- `assets/css/style.css` stile principale
- `assets/js/main.js` script minimo
- `assets/img/works/` immagini portfolio

## Come caricarlo su GitHub

1. Apri il repository `Soniagiudici`
2. Cancella o sostituisci i file esistenti
3. Carica tutti i file e le cartelle contenute in questa cartella
4. Commit changes
5. GitHub Pages aggiornerà il sito automaticamente

## Immagini

Sostituire i file `placeholder-01.jpg` ecc. con le immagini definitive, mantenendo gli stessi nomi per vedere subito il sito funzionare.
